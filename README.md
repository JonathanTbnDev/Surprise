# Site do Clan Surprise

Versão estática preparada para GitHub Pages.

## Publicação
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Escolha **Deploy from a branch**.
5. Selecione a branch **main** e a pasta **/(root)**.
6. Clique em **Save**.

O endereço ficará parecido com `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

> Login, banco MySQL e gravação do formulário estão desativados nesta demonstração estática.
